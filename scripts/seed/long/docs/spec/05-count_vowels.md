# 5. count_vowels

Module: `textkit/strings.py`. Tests: `tests/test_strings.py`.

    count_vowels(text)

Return how many characters of text are one of a, e, i, o, u, in either case. y is not a vowel.

Examples:

    count_vowels("Hello World") == 3
    count_vowels("rhythm") == 0
    count_vowels("AEIOU aeiou") == 10
