# Claude Repository Instructions

Read `AGENTS.md` first. This file only adds Claude-specific commit metadata and exists so a Claude harness that loads model-specific docs first still picks up the shared workflow.

## Git Commit Standard

All commits generated by agents MUST follow this exact template, dynamically inserting the actual model name used during the session:

```
[claude] <type>: <short description>

- <detail 1>
- <detail 2>

Docs: updated | none (<why no documented behaviour changed>)
Implements: <decision IDs built by this commit, if any>
Closes-Todo: <todo IDs finished by this commit, if any>

Co-Authored-By: <Model Name> <noreply@anthropic.com>
Harness: Claude Code
Model: <model-id>
```

Fill in the model name and ID the session actually runs (for example `Claude Opus 5.5` / `claude-opus-5-5`). The `Co-Authored-By` line is what GitHub parses for contributor attribution; `Harness` and `Model` are for traceability.

The `Docs:` trailer is mandatory and checked by CI and the `commit-msg` hook; `Implements:` and `Closes-Todo:` are written only when they apply (rules in `AGENTS.md`, "Documentation contract"). Remove the lines that do not apply; keep `Docs:`.
