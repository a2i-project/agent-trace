# Codex Repository Instructions

Read `AGENTS.md` first. This file only adds Codex-specific commit metadata and exists so a Codex harness that loads model-specific docs first still picks up the shared workflow.

## Git Commit Standard

All commits generated by Codex should follow this template, with the model the session actually runs:

```text
[codex] <type>: <short description>

- <detail 1>
- <detail 2>

Docs: updated | none (<why no documented behaviour changed>)
Implements: <decision IDs built by this commit, if any>
Closes-Todo: <todo IDs finished by this commit, if any>

Co-Authored-By: codex <codex@openai.com>
Harness: Codex
Model: <model-id>
```

The `Docs:` trailer is mandatory and checked by CI and the `commit-msg` hook; `Implements:` and `Closes-Todo:` are written only when they apply (rules in `AGENTS.md`, "Documentation contract"). Remove the lines that do not apply; keep `Docs:`.
